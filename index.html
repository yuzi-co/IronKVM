IronKVM update feed

This is the update feed for IronKVM, community firmware for the Sipeed NanoKVM. It is not a website. A device polls latest.json from here and downloads the package the manifest names.

latest.json

The manifest lives here because it is a few hundred bytes. The packages live on the repository's releases page, because they are not. The manifest names each one with an absolute URL.

IronKVM is not affiliated with Sipeed. Hardware questions belong to their wiki.
